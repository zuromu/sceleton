# scele (command line)

A small terminal version of Sceleton, for people who live in the terminal.

```bash
pipx install .      # inside this folder
scele login
scele               # today's deadlines and announcements
scele --help        # everything else: todo, sync, news, grades, ics, notify, schedule
```

It logs in the way the Moodle mobile app does when SCeLE allows it, and falls back to the normal website login when it doesn't.
